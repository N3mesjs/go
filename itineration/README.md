# Iterations in go
There is no **while** or **do-while**

The for statement takes an initial, a condition and 
what to do after every loop.

## Initial declaration
It can only be assigned with the shorthand `:=` or
outside the for loop with the explicit assignment.

## `range` keyword
This is a special keyword that go has for a shorter
syntax for the loop. the `range` returns two values
one is the **index** and one is the **value**, so it's a good
thing used for array iteraton
